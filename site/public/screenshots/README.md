# 宣传页截图占位说明

宣传页（site/）目前使用 **SVG 占位图**模拟应用界面。页面代码会自动检测同目录下的 **PNG 真实截图**，放入后无需修改任何代码即可生效。

## 如何替换为真实截图

1. 运行应用，截取以下界面（推荐 16:10 或 4:3，宽度 ≥ 1280px，PNG 格式）；
2. 按下面的命名保存到本目录（`site/public/screenshots/`），**覆盖或替换同名 PNG**；
3. 重新构建站点即可。

| 文件（放入后自动生效） | 对应页面 | 展示位置 |
|---|---|---|
| `certs-view.png` | 「我的证书」页 | Hero 主视觉（最重要） |
| `wizard-view.png` | 「申请证书」向导页 | 工作流程区（未接入，预留） |
| `dns-view.png` | 「DNS 配置」页 | 功能特性区（未接入，预留） |

## 截图建议

- **certs-view.png（Hero 主图）**：截取「我的证书」列表页，包含至少 1-2 张证书卡片（状态徽章 + 剩余天数进度条），最好带「一键申请证书」按钮；
- 截图尺寸建议 1600×1000 以上，页面会按比例缩放；
- 若应用窗口内容较多，可适当缩小窗口后再截图，保证卡片清晰；
- 若真实截图与占位图长宽比差异较大，可在 `Hero.astro` 中调整 `window-body` 的样式（`aspect-ratio`）或直接替换图片。

## 相关文件

- Hero 主视觉引用：`site/src/components/Hero.astro`（自动检测 PNG / 回退 SVG）
- 占位图源文件：`certs-view.svg`、`wizard-view.svg`、`dns-view.svg`
