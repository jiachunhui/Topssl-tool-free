本版本完成品牌统一与部署能力升级：

- **品牌统一**：应用名称更新为「ToSSL 免费SSL证书管理工具」，窗口标题、侧边栏、托盘、系统通知与关于页同步更新；
- **新增部署包导出**：在证书详情页一键生成「部署包」文件夹（包含 fullchain.pem、privkey.pem 与 nginx / Apache / IIS 配置示例），拷贝到服务器按说明配置即可完成部署；
- **新增 IIS 一键部署（Windows）**：自动把证书导入本机证书库并为所选站点添加 https 绑定（443 端口），部署全程无需手动配置（需以管理员身份运行）；
- **更新机制优化**：新增国内更新源（www.tossl.cn/updates/latest.json）优先检查，失败自动回退 GitHub Releases，国内网络检查更新更快更稳；同步修复国内清单发布时间解析问题；
- **申请向导优化**：DNS 验证标记为「推荐」（国内通用、无需 80 端口、支持通配符）；修复「确认申请信息」页返回后「开始申请」按钮被误禁用的问题；
- **设置页说明完善**：HTTP 验证端口说明明确为「本机监听端口，需配合 80 端口反向代理使用」，家庭宽带用户建议直接使用 DNS 验证；
- **官网内容扩充**：宣传站点下载页、SSL 知识库与文档中心内容持续更新。
