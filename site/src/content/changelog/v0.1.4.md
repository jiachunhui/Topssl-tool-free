本版本新增应用内检查更新与一键更新安装功能：

- **自动检查**：应用启动后自动检查新版本（每 16 小时最多联网一次），发现新版本弹出提示框，展示版本号与更新说明；
- **一键更新**：点击「立即更新」自动下载安装包并显示下载进度，完成后启动安装程序覆盖安装，原有证书与配置数据全部保留；
- **手动检查**：进入「关于」页可随时手动检查更新，已是最新版本时显示「已是最新版本」；
- **兜底通道**：更新弹窗与「关于」页均提供前往 GitHub Releases 手动下载入口；macOS 下载 dmg 后自动打开镜像，拖入「应用程序」即可完成更新。

更新后无需再手动访问 GitHub 查找安装包，新版本发布后打开应用即可完成升级。
