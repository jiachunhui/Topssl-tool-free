本版本完善核心证书申请能力：

- **证书申请向导**：输入域名即可申请，进度实时显示（端口检测 → 提交申请 → 验证 → 签发）；
- **两种验证方式**：HTTP-01 / DNS-01 验证，DNS 验证内置阿里云 DNS、DNSPod、Cloudflare 三家服务商的 API 自动验证；
- **通配符与多域名证书**：支持 `*.example.com` 通配符证书与多域名 SAN 证书；
- **自动续期**：证书到期前 30 天自动续期，通过系统通知提示续期结果；
- **测试环境**：Staging 测试环境与正式环境切换，不占用正式签发配额；
- **密钥安全存储**：DNS API 密钥经 Windows DPAPI / macOS 钥匙串 / Linux Secret Service 加密存储；
- **部署参考**：内置 nginx / Apache 部署配置示例。
