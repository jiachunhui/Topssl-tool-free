# TopSSL 免费证书助手 用户手册

版本：0.1.3

## 1. 产品简介

TopSSL 免费证书助手是一款面向普通用户的跨平台桌面程序，由 [TopSSL（topssl.cn）](https://www.topssl.cn/?utm_source=github&utm_medium=manual&utm_campaign=top) 出品并支持，帮助你**免费**为网站申请 HTTPS 证书：

- 输入域名 → 一键申请 Let's Encrypt 证书（有效期 90 天）
- 支持单域名、多域名（SAN）与**通配符证书**（`*.example.com`）
- 证书到期前 30 天**自动续期**，一次配置长期有效
- 支持 Windows / macOS / Linux

## 2. 安装与卸载

### 2.1 下载

安装包发布在 GitHub Releases（现已开源），也可通过应用内「检查更新」自动下载（见 2.4）。

| 平台 | 安装包 | 安装方式 |
|---|---|---|
| Windows 10/11 x64 | `TopSSL-Free-Cert-Assistant_<版本>_x64-setup.exe` | 双击运行，按向导安装（默认当前用户，无需管理员） |
| macOS（Apple Silicon） | `TopSSL-Free-Cert-Assistant_<版本>_aarch64.dmg` | 打开 dmg，将应用拖入「应用程序」 |
| macOS（Intel） | `TopSSL-Free-Cert-Assistant_<版本>_x64.dmg` | 同上 |
| Linux（Debian/Ubuntu） | `TopSSL-Free-Cert-Assistant_<版本>_amd64.deb` | `sudo dpkg -i xxx.deb` |
| Linux（其他发行版） | `.AppImage` / `.rpm` | `chmod +x xxx.AppImage && ./xxx.AppImage`；或 `sudo rpm -i xxx.rpm` |

### 2.2 macOS 首次打开提示

应用目前未做代码签名，首次打开时 macOS 会提示「无法验证开发者」：

- 方法一：Finder 中找到应用，**按住 Control 点击（右键）→ 打开**，再点「打开」；
- 方法二：终端执行 `xattr -cr /Applications/TopSSL-Free-Cert-Assistant.app` 后重新打开。

### 2.3 卸载

- Windows：设置 → 应用 → 卸载，或在安装目录运行卸载程序。卸载后如需彻底清理，删除 `%APPDATA%\com.topsl.ssl-cert-desktop\`（其中包含证书文件，**删除前请确认已备份或不再需要**）。
- macOS：将应用拖入废纸篓；数据位于 `~/Library/Application Support/com.topsl.ssl-cert-desktop/`。
- Linux：`sudo apt remove ssl-cert-desktop`；数据位于 `~/.local/share/com.topsl.ssl-cert-desktop/`。

### 2.4 软件更新

应用会**自动检查新版本**（国内更新源优先，不可用时自动回退 GitHub Releases）：

- **启动静默检查**：每次启动后台检查一次（每 6 小时最多联网一次），发现新版本弹出提示框，展示版本号与更新说明；点「稍后提醒」后该版本不再打扰，点「立即更新」自动下载安装包（显示下载进度）并启动安装程序（Windows 下会自动退出应用再运行安装器覆盖安装，数据保留）。
- **手动检查**：进入「关于」页点击「检查更新」，可随时强制联网检查；已是最新时显示「已是最新版本」。
- **手动下载兜底**：更新弹窗与「关于」页均提供「前往 GitHub 查看」入口，可跳转 GitHub Releases 手动下载安装。
- macOS 通过弹窗下载 dmg 后自动打开镜像，拖入「应用程序」即完成更新；Linux 跳转 GitHub Releases 手动下载对应包。

> 注意：安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。

## 3. 快速开始：申请第一张证书

1. 打开应用，进入「申请证书」页；
2. 填写**主域名**（如 `www.example.com` 或 `*.example.com`），可添加多个**其他域名**（多域名证书）；
3. 核对信息，选择验证方式：
   - **HTTP 验证（推荐）**：无需任何配置，程序自动在 80 端口临时开启验证服务；
   - **DNS 验证**：需先在「DNS 配置」页配置好 DNS 服务商 API 密钥（自动添加解析），或选择手动添加 TXT 记录；
4. 选择环境：**测试环境**（不消耗正式额度，证书不被浏览器信任，用于验证流程）或**正式环境**（浏览器信任，注意 Let's Encrypt 速率限制）；
5. 等待 1–3 分钟，流程进度实时显示（端口检测 → 提交申请 → 验证 → 签发）；
6. 申请成功后，在「证书详情」中可查看证书文件路径、到期时间与部署指引（nginx / Apache 配置示例）。

## 4. 验证方式详解

### 4.1 HTTP-01 验证（推荐）

程序在本地 80 端口临时启动验证服务，Let's Encrypt 服务器访问 `http://你的域名/.well-known/acme-challenge/...` 完成验证。

**前提条件：**

- 域名的 A/AAAA 记录已指向**本机公网 IP**；
- 本机 80 端口可被公网访问（云服务器安全组 / 家庭宽带路由器需放行 80 端口）；
- 端口未被占用（Apache/nginx 若占用了 80 端口，请先停止，申请完成后再恢复）。

**Linux 额外步骤**：普通用户无法监听 1024 以下端口，需一次性授权：

```bash
sudo setcap cap_net_bind_service=+ep /path/to/topssl-free-cert-assistant
```

HTTP 验证端口可在「设置」页修改（一般无需改动）。

### 4.2 DNS-01 验证

程序调用 DNS 服务商 API 自动添加 TXT 记录完成验证，**适合**：

- 通配符证书（`*.example.com`）—— 仅 DNS 验证支持；
- 服务器 80 端口不可公网访问（如内网服务器、CDN 前置）；
- 域名解析不在本机。

程序会轮询检测记录生效后自动提交验证；验证完成后自动清理 TXT 记录。也可选择「手动添加解析记录」：程序给出主机记录与记录值，你到服务商后台手动添加，生效后点「继续」。

## 5. DNS 服务商配置

进入「DNS 配置」页，添加服务商并填入 API 密钥：

| 服务商 | 所需凭证 | 获取位置 | 最小权限 |
|---|---|---|---|
| 阿里云 DNS | AccessKey ID + AccessKey Secret | 阿里云 RAM 访问控制 → 创建子用户 | `AliyunDNSFullAccess` |
| DNSPod / 腾讯云 | API Token（ID + Token） | DNSPod 控制台 → 密钥管理（旧版 dnsapi.cn Token） | 域名解析读写 |
| Cloudflare | API Token | Cloudflare 控制台 → My Profile → API Tokens | `Zone:DNS:Edit` |

密钥加密存储于操作系统安全存储（Windows DPAPI / macOS Keychain / Linux Secret Service），数据库仅保存引用标识，不会以明文落盘。

## 6. 证书管理

「我的证书」页展示所有已申请证书：域名、到期时间、状态。点击证书卡片可查看：

- **证书文件路径**：`fullchain.pem`（证书链）、`privkey.pem`（私钥）；
- **部署指引**：nginx / Apache 配置示例；
- 续期记录与下次续期时间。

### 证书文件位置

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\com.topsl.ssl-cert-desktop\certs\{域名}\` |
| macOS | `~/Library/Application Support/com.topsl.ssl-cert-desktop/certs/{域名}/` |
| Linux | `~/.local/share/com.topsl.ssl-cert-desktop/certs/{域名}/` |

> 私钥文件权限为 0600，请勿外泄。备份时请将整个证书目录一并复制。

## 7. 自动续期

- 证书有效期 90 天，程序在**到期前 30 天**自动发起续期（同一流程重新验证、重新签发）；
- 依赖「设置」中开启**自动续期**与**开机自动启动**；程序常驻系统托盘，请勿退出；
- 续期结果通过系统通知提示；失败时请打开「日志」页排查（常见原因：DNS 密钥过期、80 端口被占、域名解析变更）。

## 8. 设置项说明

| 设置项 | 说明 |
|---|---|
| 申请环境 | 测试环境（Staging，不消耗正式额度、证书不被浏览器信任）或正式环境 |
| HTTP 验证端口 | HTTP-01 验证监听的端口（默认 80，一般无需修改） |
| 邮箱 | ACME 账户注册与到期通知邮箱（强烈建议填写，用于接收续期提醒） |
| 证书密钥类型 | RSA / ECDSA 密钥算法 |
| 开启自动续期 | 到期前 30 天自动续期总开关 |
| 开机自动启动 | 登录系统后自动启动并驻留托盘 |

## 9. 日志与排错

「日志」页实时展示后端日志（ACME 流程、DNS 操作、续期调度等）。常见问题：

| 现象 | 原因与处理 |
|---|---|
| 80 端口检测失败 | 端口被占用或未放行；检查防火墙/安全组，或改用 DNS 验证 |
| HTTP 验证超时 | 域名未解析到本机公网 IP，或运营商封锁 80 端口 |
| DNS 验证超时 | API 密钥无权限/已过期；记录传播较慢，可稍后重试或手动添加 |
| 申请被拒（正式环境） | 触发 [Let's Encrypt 速率限制](https://letsencrypt.org/docs/rate-limits/)（每域每周 50 张），可先用测试环境 |
| 续期失败 | 密钥过期、端口被占、域名解析变更；查看日志定位 |

## 10. 常见问题（FAQ）

**Q：测试环境证书浏览器报不安全？**
A：正常现象。测试证书用于验证申请流程，请用正式环境申请真实证书。

**Q：申请正式证书有限制吗？**
A：Let's Encrypt 限制每域名每周 50 张正式证书，90 天内重复申请同一套域名会返回「已签发」，属正常现象。

**Q：换服务器后证书怎么办？**
A：证书文件可随目录整体拷贝到新服务器使用；DNS 验证的证书与服务器无关，重新部署即可。

**Q：程序退出后还会自动续期吗？**
A：不会。请保持程序在系统托盘运行（建议开启开机自启）。

**Q：证书私钥安全吗？**
A：私钥文件权限 0600，仅本机用户可读；DNS API 密钥存于操作系统加密存储。
