### 5.1 软件分发站（国内对百度最有效，且直接带用户）

目标站点：**小众软件、异次元软件世界、蓝点网、果核剥壳、大眼仔旭、423down、mefcl、ZAPRO** 等。
投稿入口一般在站点「投稿」页或联系邮箱；通常需要：软件介绍 + 截图 + 下载链接 + 官网链接。

**通用投稿文案**（可直接使用或按站点风格微调）：

```text
标题：ToSSL —— 免费申请与自动续期 SSL 证书的桌面工具（Windows / macOS / Linux）

正文：

网站启用 HTTPS 需要 SSL 证书，Let's Encrypt 提供免费证书，但申请和续期要走命令行工具
（certbot、acme.sh），对不熟悉 Linux 的用户有门槛；证书有效期只有 90 天，忘记续期就会
导致网站报 HTTPS 错误。

ToSSL 是一款把这件事图形化的免费桌面工具：

- 输入域名即可申请 Let's Encrypt 证书，支持 HTTP 验证与 DNS 验证（DNS 验证可申请通配符证书）
- DNS 验证内置阿里云、DNSPod、Cloudflare 三家服务商 API，自动添加与清理 TXT 记录，不依赖 80 端口
- 证书自动安装到本机，一键导出部署包（含 nginx / Apache / IIS 配置示例）；Windows 服务器可一键部署到 IIS
- 到期前 30 天自动续期，开机自启后静默驻留系统托盘，不打扰使用
- 换电脑时可把证书、设置、DNS 凭据打包成一个口令加密的备份文件，在新电脑导入即可继续使用
- 支持 Windows / macOS / Linux，MIT 协议开源

官网（含下载、图文教程与知识库）：https://www.tossl.cn

截图建议放 2-3 张：我的证书列表、申请向导、DNS 验证配置
```

**以技术回答的形式**作答，末尾自然带出工具（不要一上来就推产品，容易被判定为广告）。

```text
先说结论：个人或小站点用 Let's Encrypt 的免费证书就够了，90 天有效期，成本为零。

申请方式有三种：
1）命令行工具 certbot / acme.sh —— 功能最全，但需要会用命令行，续期要靠定时任务
2）云厂商控制台申请 —— 免费额度有限，且证书和平台绑定
3）图形化桌面工具 —— 适合不熟悉命令行的用户

以图形化工具为例，整个流程大概是：
① 输入域名（通配符如 *.example.com 也可以）
② 选验证方式：80 端口能被公网访问就用 HTTP 验证；不能就用 DNS 验证
   （DNS 验证支持 API 自动添加 TXT 记录，也适用于内网服务器和 CDN 前置场景）
③ 等待签发完成，证书落到本机，导出部署包（含 nginx / Apache / IIS 示例配置）
④ 开启自动续期，到期前 30 天自动续签，不用再记着这件事

我用的是 ToSSL（开源免费的桌面工具，Windows/macOS/Linux 都有），
地址是 https://www.tossl.cn，上面的流程就是它的操作步骤，可以参考。
如果你更习惯命令行，certbot 也完全够用，看个人习惯。
```
